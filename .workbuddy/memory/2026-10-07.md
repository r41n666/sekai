### ⚠ 关键决策：`AudioStreamWAV.load_from_file()` 运行时直读 ⇒ **无需 Godot 导入**
主理人实测：
```
FileAccess.exists        = true
load_from_file()         = ✅ format=1 mix_rate=44100 stereo=true 165464B(0.94s)
ResourceLoader.exists    = false   ← 证实 Godot 从未导入它
```
若走常规 `load()`，未导入状态下拿到 `null`；补导入需 `--import`（有删 Vulkan 锁的历史，已 7 次）
或开编辑器（违反硬约束）⇒ `load_from_file` 是唯一零风险路径。**本轮因此完全没碰 project.godot。**
三级降级：`file_exists`→`load_from_file`（主路径）→`ResourceLoader.exists` 为真才 `load()`→bot 退回合成音。
`_build_hit_sound()` **保留为 fallback** 未删。
⚠️ 已知限制：无 `.import` ⇒ **导出 PCK 时不会被打包**（只影响未来导出）。
