## 1. High Concept（一句话概念）

> **《Miku 水面竞技场》是一款初音未来主题、4 人以内的快节奏联机对枪小游戏：在一片明亮的镜面水面上，用可学习的三层后坐力打「5 分钟 15 杀」一局的短平快个人死斗，死即重生、即开即战。**

补充定位三要素：
- **题材**：初音未来 / Miku 主题（氛围载体，非剧情）。
- **玩法**：第三人称 + 可切第一人称的快节奏多人对枪（hitscan + 三层后坐力），模式 = **个人死斗（FFA）**。
- **规模**：小游戏 —— 单局 5 分钟 / 15 杀、4 人、局域网 / 蓝盾 VPN 直连。

### 2.3 Aesthetics（美学 —— 玩家最终感受到什么）

结论与 `pillars.md` §5 一致：**Sensation（感官）+ Challenge（挑战）+ Fellowship（社交）**。

- **Sensation** ← 三层后坐力 / 震屏 / 枪声随机化 / 动态准星 / 命中标记 / 击杀日志。
- **Challenge** ← 对枪胜负、压枪技巧、弹道学习、FFA 的「先到 15 杀」抢分。
- **Fellowship** ← 4 人联机、队友图标、击杀日志、蓝盾 VPN 熟人局。

## 3. 靶玩家定位

### 3.1 Bartle 玩家类型

| Bartle 类型 | 权重 | 本作如何服务 |
| --- | --- | --- |
| **Killer（杀手 / 对抗型）** | ★★★ 核心 | 核心循环就是「找到并击杀对手」；胜负条件 = **FFA 先到 15 杀**（见 `01_core_loop.md`）。这类玩家是 MVP 的第一目标。 |
| **Achiever（成就型）** | ★★ 次要 | 技巧成长（背弹道 / 压枪）、外观收集（角色模型 / 武器外观 / 皮肤）、击杀数记录。**当前**缺少成就/统计系统，属目标层待补。 |
| **Explorer（探索型）** | ★ 弱 | 无开放地图、无隐藏内容；地图是竞技空间而非探索空间。 |
| **Socializer（社交型）** | ★★ 辅助 | 4 人熟人局、昵称、击杀日志。但**无聊天 / 无观战 / 无表情**——社交是「一起打」而非「一起聊」。 |

> **结论**：本作靶心是 **Killer + 轻微 Achiever**，用 Fellowship 作为「有人一起打」的容器。所有设计决定以 Killer 的体验为第一优先。

### 3.2 自我决定论（SDT）三需求满足度

| 需求 | 本作如何满足 | 现有证据 | 缺口 |
| --- | --- | --- | --- |
| **自主（Autonomy）** | 自选 4 个武器槽的**外观**与**皮肤**、自选角色模型（9 个）、自由选择姿态 / 视角 / 打法风格 | `game_menu.gd`（角色 / 外观 / 皮肤）；`weapon_variant.gd::VARIANTS`；`weapon_skin.gd` | 外观/皮肤**不同步**给其他玩家（README 已知限制）——「表达」的社交价值被削弱 |
| **胜任（Competence）** | 后坐力可学习（固定弹道）、技巧可成长、命中反馈即时清晰、FFA 有明确目标 | `recoil_system.gd` 固定种子；命中标记 + 击杀日志；**新增 FFA 15 杀目标** | 缺少可见的成长/统计面板（目标层补） |
| **关联（Relatedness）** | 4 人联机、队友图标、击杀日志、昵称、**共同的抢分目标** | `network_manager.gd`、`teammate_icons.gd`、`hud.gd::push_kill` | 无队伍/无语音/无观战 |

> 关键洞察：**关联需求当前最弱**——因为**原本没有胜负条件**，4 个人只是「一起存在」，不是「一起战斗」。**用户拍板 FFA 后，关联需求被激活**：即便各自为战，也有「同一个 15 杀目标 + 比分板」的共同语境。

## 4. 范围分层（Scope Tiers）

> 定位是「小游戏」，**MVP 必须克制**。以下分层以「能否复用现有代码」为硬约束。

### 4.1 MVP（最小可玩 —— 让它成为「一局完整的游戏」）

| # | 交付 | 复用现有代码 | 为什么进 MVP |
| --- | --- | --- | --- |
| M1 | **胜负条件：个人死斗（FFA）先到 15 杀 / 5 分钟** ✅ 已决 | `network_manager.gd` 加比分 RPC；`hud.gd::push_kill` 已能写击杀 | 无胜负是最大空洞，不补就不算游戏 |
| M2 | **完整对局流程状态机**（大厅 → 出生 → 交战 → 结算 → 再开） | `hub.gd` / `main.gd` / `death_screen.gd` 微改 | 让 M1 有承载 |
| M3 | **一张可玩的 80×80 m 竞技图**（掩体 / 通道 / 4 出生点） ✅ 尺寸已决 | `main.tscn` 加 `Obstacles`（`minimap_obstacle` 组） | 现在只有空地 + 风景，没有对枪空间 |
| M4 | **结算面板**（比分板 + 击杀/死亡统计） | `hud.gd` | 一局的闭环 |
| M5 | **玩家受伤音效**（补 `hit_player.ogg` 占位） | `player.gd::take_damage()` | README 明确列出的缺口 |

**MVP 明确不做**（已由用户拍板确认）：队伍/兵种、**经济购买（⚑C-3 不引入）**、**护甲 / 伤害衰减（⚑E-2 不引入）**、目标点模式、服务器权威、断线重连、观战、皮肤联机同步、真实音效素材。

### 4.2 目标（Target —— 让「小游戏」变成「值得反复玩的小游戏」）

- **团队死斗（TDM 2v2）** + 队伍系统 + 队伍颜色/图标（**目标层待议，MVP 不做**）。
- **半经济**（击杀回血 / 补给）——**MVP 不做，目标层再议**，见 `02_combat_economy.md`。
- **武器数值分化**：让 AK-47 / M4A4 拥有独立数值（而非纯外观）。
- **护甲 / 伤害衰减**规格——**MVP 不做，目标层再议**。
- **统计与档案**：KD、胜场、最长连胜（Achiever 需求）。
- **皮肤 / 外观联机同步**。
- **第二张地图**（对称布局，防止「背图」偏向一方）。

### 4.3 愿景（Vision —— 长期方向，明确标注为「非承诺」）

- **回合制目标点模式**（占点读条，先赢 N 回合）。
- **服务器权威 + 延迟补偿**（反作弊与一致性）。
- **真实动画剪辑**（替换程序化步态）+ 真实音效素材 + 音频总监介入。
- **断线重连 / 观战 / 服务器列表**。
- **有限探索元素**：可上下的垂直掩体、可交互场景物件。
