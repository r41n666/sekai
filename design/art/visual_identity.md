## ① 视觉主题（一句话）

> **「一场开在水面上的初音未来全息演唱会」** —— 玩家在一片倒映着蓝天白云的镜面水台上对枪，周围是舞台灯箱般的明亮道具，天地一片通透的蓝白，唯一的强色是 Miku 的青与舞台的品红。

**关键词**：明亮、通透、高饱和点缀、镜面、干净、无军事感。
**一句话检验**：任何资产若让你联想到"战场"而不是"舞台"，就不通过。

### 2.3 色彩使用配额（重要）

| 层 | 允许的色彩 | 说明 |
| --- | --- | --- |
| **背景层**（天空 / 水 / 云） | 只有蓝白 cold 色系 | 现状保留，**不引入暖色或高饱和**，保证舞台"干净" |
| **中性层**（掩体主体） | Miku 青 `#2FB3AE` 一档为主体色 | 掩体是舞台道具，统一青系，避免五颜六色 |

> **配额原则：背景 80% 蓝白、中性 18% 青、信号 2% 黄/品红。** 任何画面切片里，信号色面积超过 ~5% 即为超标（见 `accessibility.md` §4 视觉噪声预算）。

## ③ 形状语言

| 类别 | 形状规则 | 理由 |
| --- | --- | --- |
| **掩体** | **倒角立方体 / 矩形板**，直角、干净、无破损 | 舞台灯箱感；可读性强；图元成本最低 |
| **垂直物** | 高瘦立柱（C6 `1.2×1.2×4.0`）作视觉锚点 | 打破全平面水平线，给 3D 空间纵深感 |
| **边界** | 完整的**圆环**（B1 `R=40`）+ 同环位的**隐形碰撞墙**（高 2.5、厚 0.3，⚑A-3 = A+墙） | 呼应原参考图（`sky.jpeg`，🗑 已删除）的全息魔法阵；"舞台边界"的语义；隐形墙防出界 |
| **HUD** | 细线 + 直角 + 少量箭头（现状已符合） | 战地风细线 HUD，与"干净舞台"一致 |
| **禁忌形状** | ❌ 沙袋（不规则软体）、❌ 锈蚀破洞、❌ 铁丝网、❌ 反坦克拒马 | 军事语汇，违反 P3 |

> **形状一致性**：全图不许出现"破损 / 有机 / 写实磨损"的轮廓。所有掩体都是**完好、规整、有倒角**的舞台装置。

## ④ 材质语言

### 4.1 三条硬规则

1. **非金属化**：掩体 `metallic = 0.0`。亮天空下金属会反射天空变白，失去对比（见 `asset_spec_arena.md` §4.2）。
2. **高饱和、中明度**：主体落在明度 0.5~0.75、饱和度 0.6~0.9 区间，**避开近白**（近白 = 与天空融为一片）。
3. **无写实脏污贴图**：全程序化纯色材质，**0 张外部贴图**。

### 4.2 材质分层公式

> **每个掩体 = 暗色底座裙边 + 高饱和主体 + 功能色顶面**

- **底座**（`#1B2A38`，外扩 0.05 m、高 0.35 m）：在亮背景下压出**暗色剪影基线**，弥补水面太光滑、SSAO 抓不到接触阴影的问题；
- **主体**（`#2FB3AE`，`roughness 0.45`）：提供色彩与体积；
- **顶面**（可站立 `#FFD34D` / 不可站立 `#1B2A38`）：**功能色语言**，一眼判断"能不能上"。

### 4.4 角色剪影语言（✅ 已决 ⚑A-2 = **C · 描边 + 假接触阴影**）

> **本节的"目标"已定，"实现方式"待 `engineering-lead` 验证（见降级路径）。**

| 项 | 内容 |
| --- | --- |
| **目标（用户拍的是这个）** | 在「近白天空 + 镜面水」下，任意距离的角色都有**可辨轮廓**且**贴在水面上**（不"漂"） |
| **H1 · 轮廓描边** | 自机 = Miku 青 `#39C5BB`，其他玩家 = 舞台品红 `#FF5C8A`，屏幕宽 ≈ 2 px；**必须走独立几何 pass，不得碰 `material_override`**（否则与 `weapon_skin.gd` 皮肤互相覆盖）→ ⚠ 实现方式待 engineering-lead 验证 |
| **H2 · 假接触阴影** | 脚下贴 `1.2 m` 半径径向暗色 decal（`#1B2A38`，中心 alpha 0.5→边缘 0）；水面 `roughness 0.06` 太光滑、SSAO 抓不到落影 → ⚠ 实现方式待 engineering-lead 验证 |
| **H3 / H4** | H3（深色舞台肩饰）列为后续增强；H4（敌我描边色区分）随 H1 一并生效 |

**可测验收（SR-1~SR-6，完整见 `asset_spec_arena.md` §6.4）**：
- **SR-1 角色躯干与背景明度差 ≥ 0.25**（现状 < 0.05；这是"一眼可读"的阈值）
- **SR-3 落地影**：脚下暗区半径 ≥ 0.8 m、与水面明度差 ≥ 0.15
- **SR-4 25 m 远距仍满足 SR-1**（核心目标）
- **SR-5 全色盲（灰度）下仍成立**（不靠色相）

**降级路径（若不满足 SR-1/SR-4，按序回退；`asset_spec_arena.md` §6.5 有完整表）**：

| 情形 | 降级方案 | 可读性损失 |
| --- | --- | --- |
| H1 独立 pass 不可行 | 材质侧 **Fresnel rim light**（不新增 pass） | **小~中** |
| TAA 下描边拖影 | 几何加粗描边（TAA 友好）或 宽度 ≥3 px | **中** |
| H1 整体不可行 | 回退 **H3 深色肩饰 + H4 色块**（仅角色内部对比，**不解决对空轮廓**） | **大**（须回报 team-lead） |
| H2 不可行 | 朝下扁平暗 quad / 局部软阴影 | **小** |

> **底线**：无论走哪条降级，**SR-4「25 m 可识别」不得失守**；若失守（走到 H1 整体不可行），说明"亮舞台可读性"这一 P3 核心未达成，必须重新评估。

## ⑤ 光照基调

| 项 | 现状 | 美术意图 | 处置 |
| --- | --- | --- | --- |
| `DirectionalLight3D` | `energy 1.2`、暖白 `#FFF5E6`、4-split 阴影 | 明亮"日光舞台" | **保留**，不加补光 |
| 天空辐射 | `ambient_light_energy 1.0`、`sky_contribution 1.0` | 通透均匀的舞台光 | **保留** |
| ACES 色调映射 | `white 6.0` | 高调、柔和 | **保留**（现状偏"过曝"，见下） |
| Glow | `bloom 0.2` / `hdr_threshold 0.9` | 舞台辉光 | **保留**，但**限制 emissive 物件 ≤ 2**（避免糊） |
| 体积雾 | `density 0.004` | 空气感 | **保留**，注意远景减透（见风险） |
| SSAO | `radius 0.5` / `intensity 2.0` | 接触阴影 | **保留**；水面太光滑抓不到接触阴影 → 靠 §4.2 底座 + 角色假阴影补 |

### 5.1 光照基调的两个问题与对策

| 问题 | 现象 | 对策 |
| --- | --- | --- |
| **整体过曝** | 现状画面"高调发灰"，天空近白，角色白裙被吃掉 | **不调光照**（不擅自改现有环境）；改用**材质对比**（掩体避开近白）+ **角色描边/假阴影**（✅ 已决 ⚑A-2 = C，见 §4.4 与 `asset_spec_arena.md` §6）来制造层次 |
| **辉光 + 雾叠加** | 亮面易 bloom 糊成一片，远景发白 | 限制 emissive ≤ 2 处；信号色面积 ≤ 5%；后期若实测远景掩体发白，提饱和 `+10%` |
